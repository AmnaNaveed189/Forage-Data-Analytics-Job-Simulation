# Forage Data Analytics Job Simulation

This project applies data analytics and machine learning to predict customer
delinquency. It was completed as part of the Forage Gen-AI Powered Data Analytics job
simulation.

## What I Learned

During this simulation, I worked on:

- **Exploratory Data Analysis & Risk Profiling** - exploring customer data and
  identifying meaningful patterns
- **Predicting Delinquency with AI** - understanding how AI can identify
  customers at risk of missing payments
- **Business Reporting & Data Storytelling** - converting analytical findings
  into clear and meaningful business insights
- **AI-Driven Collections Strategy** - exploring how predictive insights can
  support better business decisions and customer engagement

## Deliverables

- `01_EDA.ipynb` and `01_EDA_Report.docx` - exploratory data analysis
- `02_Model.ipynb` and `02_Model_Report.docx` - model development and evaluation
- `03_Business_Summary_Report.docx` - business-focused recommendations
- `PPT for stakeholders.pptx` - stakeholder presentation
- `Delinquency_Prediction_Cleaned.xlsx` - cleaned analysis dataset
